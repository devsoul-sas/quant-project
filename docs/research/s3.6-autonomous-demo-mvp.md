## P3 — Autonomous Demo Runner

Estado: **PASS en pruebas deterministas y P1 live**.

Comando disponible:

```bash
uv run devsoul-quant autonomous-demo --help
```

Modos:

- `OBSERVE_ONLY`;
- `SHADOW_TRADING`;
- `DEMO_INTEGRATION`;
- `DEMO_EXPLORATORY`.

`REAL_TRADING`, `REAL` y `REAL_MONEY` se rechazan estructuralmente. `NO_TRADE` es el estado inicial y los modos demo no ejecutan órdenes sin `--arm-demo`.

Estrategias disponibles:

- `EVEN_ODD`;
- `MOMENTUM` Rise/Fall;
- `CONTROLLED_RANDOM`, baseline determinista para integración.

Over/Under no se ejecuta.

El runner muestra como JSON efímero:

- conexión, instrumento y estrategia;
- ticks procesados y señal;
- balance virtual y P/L;
- contratos abiertos y liquidados;
- win rate, break-even y drawdown;
- estado de riesgo, tiempo y motivos de abstención.

No escribe market data ni métricas de sesión a archivos o base de datos.
