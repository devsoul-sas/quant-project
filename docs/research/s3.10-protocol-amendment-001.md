## B1. Convención uniforme del intervalo de confianza

Los protocolos originales definían `d_t = Brier(candidato) − Brier(baseline)`, donde un
valor negativo representaba mejora, y gateaban sobre un límite inferior negativo. Esta
convención es propensa a error y contradice el código del evaluador S3.8, que ya usa la
convención opuesta.

Se adopta, de forma uniforme para H1 y H2:

```text
improvement = loss_baseline - loss_candidate
```

Consecuencias (fail-closed):

- Un valor positivo de `improvement` representa mejora.
- El límite inferior del intervalo debe ser estrictamente positivo para promocionar.
- El efecto observado debe superar el umbral de relevancia práctica preregistrado.
- La inferencia respeta dependencia temporal y corrección por comparaciones múltiples.

El gate queda formalizado en `passes_improvement_gate(...)` (application/adaptive_shadow.py)
y probado con casos sintéticos favorables, cruzando cero, desfavorables e irrelevantes
(tests/application/test_improvement_gate.py). Un gate estadístico superado NO implica
rentabilidad: la elegibilidad económica es un gate separado (`mean_estimated_value > 0`).

## B2. Potencia y tamaño de muestra explícitos (H1)

| Parámetro | Valor |
|---|---|
| Unidad de observación | transición de paso up/down entre ticks consecutivos |
| Efecto mínimo relevante (marginal) | |p_up − 0.5| = 0.03 |
| Efecto mínimo relevante (lag-1) | asimetría de transición de igual magnitud |
| Nivel de significancia | α = 0.05 (two-sided) |
| Potencia objetivo | 80 % |
| Corrección por multiplicidad | FWER 5 %, Holm, familia de 2 tests (marginal + lag-1) |
| Tamaño nominal mínimo | n ≈ 2.178 transiciones (δ=0.03, p=0.5) |
| Tamaño efectivo mínimo | `n_eff = n / (1 + 2·Σρ)` ≥ 2.178 |
| Método de dependencia temporal | bootstrap por bloques (moving-block) sobre la serie de score-diferencias |
| Warm-up | 120 transiciones (estimación de frecuencia congelada) |
| Longitud de bloques | 60; sensibilidad ell/2, ell, 2ell |
| Condiciones de abstención | transiciones `FLAT` excluidas; si la fracción `FLAT` > 5 % ⇒ abstención y señal de calidad |

`FLAT` se define como `step == 0` entre ticks consecutivos. En Step Index el paso es no
nulo por construcción documentada; si la observación contradice esto (tick repetido), la
transición se descarta y NO se imputa dirección. No se eliminan empates retroactivamente.

## B3. Revisión prospectiva de H1 (Step Direction)

Preservando `STEP_DIRECTION_DEPENDENCE_V1` como hipótesis original, se fija:

- Baselines: `MEMORYLESS` (frecuencia congelada en warm-up) como primario;
  `FREQUENCY_CAUSAL` (frecuencia causal acumulada) como control.
- Modelo candidato: `MARKOV_1` (P(UP | dirección anterior) con suavizado).
- Tratamiento de `FLAT`: exclusión causal, nunca imputación de dirección.
- Discontinuidades y ticks faltantes: una brecha de `epoch` no convierte dos ticks
  no adyacentes en una transición consecutiva; se exige `epoch` estrictamente creciente
  y sin salto temporal implícito (el horizonte predictivo es el siguiente tick del
  proveedor, no el siguiente tick observado).
- Correspondencia horizonte predictivo ↔ contractual: el contrato mapeado es Rise/Fall
  `tick` (liquidación `exit vs entry`); la predicción es sobre el mismo tick de
  liquidación, no sobre un tick observado desfasado.
- Suavizado de probabilidades: las predicciones se recortan a [ε, 1−ε] y `MARKOV_1`
  usa suavizado Dirichlet α=1 para evitar ceros.
- Estabilidad temporal: se reportan mitades cronológicas y límite inferior bootstrap;
  una mejora confinada a una mitad no promociona.

## B4. Revisión de H2 (Jump Digit) — `DEFERRED`

La matriz Markov 10×10 estimada con 120 observaciones de calentamiento es
sub-potenciada: 100 celdas para ~120 muestras ⇒ muchas celdas sin masa MLE y
probabilidades nulas que producen log-loss infinito OOS.

Se introduce `CategoricalTransitionEstimator` (domain/markov_estimate.py) y se evalúa
con datos sintéticos (tests/domain/test_markov_estimate.py):

- MLE (α=0) asigna probabilidad cero a transiciones no vistas ⇒ log-loss ∞.
- Suavizado Dirichlet/Laplace α=1 nunca asigna cero y mantiene log-loss finito.
- La frecuencia marginal es el objetivo de shrinkage de referencia.
- Un warm-up mayor estrecha el hueco de estimación sin anular el suavizado.

Decisión parsimoniosa preregistrada (antes de observar mercado): suavizado Dirichlet
α=1 como única alternativa autorizada para H2. **H2 permanece `DEFERRED`** hasta nueva
autorización; no se ejecuta en esta etapa.
